# Структура файловой системы Linux

## Введение

Linux использует единую иерархическую файловую систему.

В отличие от Windows, где используются диски C:, D:, E:, в Linux всё начинается с корневого каталога: /

Все остальные директории являются его подкаталогами.

---

# Основные директории Linux


## /

Корневой каталог.

Это начало всей файловой системы Linux.

Все остальные директории находятся внутри `/`.

ls /
afs/          boot/         home/         lost+found/   opt/          run/          srv/          usr/
.autorelabel  dev/          lib/          media/        proc/         sbin/         sys/          var/
bin/          etc/          lib64/        mnt/          root/         shared_dev/   tmp/

---

Основные каталоги
/
Корневой каталог.
Начало всей файловой системы Linux.

/boot
Файлы загрузки системы.
Содержит:ядро Linux;initramfs;файлы загрузчика.
Используется при запуске системы.

/etc
Конфигурационные файлы системы и программ.
Здесь находятся настройки:
сервисов;сети;пользователей;systemd.
На моём сервере:
/etc/nginx
/etc/fail2ban
/etc/systemd

/home
Домашние директории обычных пользователей.
Пример:/home/user

/root
Домашняя директория администратора root.
На моём сервере: /root/projects/devops-notes
содержит Git-репозиторий с документацией.

/usr
Основные программы, библиотеки и документация системы.
Примеры:
/usr/bin
/usr/lib
/usr/share

/var
Данные, которые постоянно изменяются во время работы системы.
Содержит: логи;базы данных;кэш;данные сервисов.
На моём сервере:
Docker: /var/lib/docker
Логи: /var/log

/tmp
Временные файлы.
Используется программами для хранения временных данных.
Обычно очищается после перезагрузки.

/run
Временные данные работающих процессов.
Содержит:PID-файлы;сокеты;
runtime-информацию.
Создаётся заново при загрузке системы.

/proc
Виртуальная файловая система ядра Linux.
Содержит информацию о:процессах;памяти;CPU;параметрах ядра.
Примеры:
cat /proc/cpuinfo
cat /proc/meminfo

/sys
Интерфейс для взаимодействия с ядром Linux.
Используется для работы с: устройствами;драйверами;параметрами ядра.

/dev
Специальные файлы устройств.
Linux использует принцип:
всё является файлом
Примеры:
/dev/vda1
/dev/null
/dev/random
На VPS:
/dev/vda1 основной виртуальный диск.

/opt
Дополнительное программное обеспечение.
Используется сторонними приложениями.
Пример:
/opt/application

/srv
Данные, которые предоставляет сервер.
Например:сайты;файлы пользователей;данные приложений.

/mnt
Временные точки монтирования.
Используется для подключения:
дополнительных дисков;
сетевых хранилищ.

/media
Точки подключения внешних устройств.
Например:USB;внешние диски.

/lib и /lib64
Системные библиотеки Linux.
Необходимы для работы программ и ядра.
