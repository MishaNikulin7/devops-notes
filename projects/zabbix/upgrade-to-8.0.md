# Zabbix 7.0 → 8.0: обновление Docker-инфраструктуры

**Дата:** 05.11.2026  
**ОС:** AlmaLinux 9  
**Развёртывание:** Docker Compose  
**СУБД:** MySQL

## 1. Цель

Обновить Zabbix до 8.0 LTS без потери конфигурации, истории мониторинга и настроенных уведомлений.

### Обновлённые компоненты

| Компонент | До | После |
|---|---|---|
| Zabbix Server | 7.0 LTS | 8.0.0 |
| Zabbix Frontend | 7.0 LTS | 8.0.0 |
| MySQL | 8.0.42 | 8.4.13 |
| Zabbix Agent | 6.0.48 | 8.0.0 |

## 2. Подготовка

Перед обновлением выполнены:

- Резервное копирование MySQL через `mysqldump`.
- Создание файловой копии каталога MySQL при остановленной СУБД.
- Резервное копирование Docker Compose и конфигураций.
- Проверка совместимости MySQL с помощью MySQL Shell Upgrade Checker.

**Результат проверки MySQL:** 0 ошибок, 20 предупреждений, 2 уведомления. Критических препятствий для обновления не обнаружено.

## 3. Обновление MySQL

В `.env` изменена версия образа:

```ini
MYSQL_IMAGE_TAG=8.4-oracle
```

После остановки компонентов Zabbix выполнено:

```bash
docker compose up -d --no-deps mysql-server
```

По журналам подтверждено успешное обновление структуры базы данных с MySQL 8.0.42 до 8.4.13.

Перед обновлением самого Zabbix создан дополнительный SQL-бэкап уже на MySQL 8.4.

## 4. Обновление Zabbix

В `.env` изменена версия:

```ini
ZABBIX_ALPINE_IMAGE_TAG=alpine-8.0
```

Скачаны новые образы:

```bash
docker compose pull zabbix-server zabbix-web-nginx-mysql
```

Компоненты обновлены последовательно:

```bash
docker compose up -d --no-deps zabbix-server
docker compose up -d --no-deps zabbix-web-nginx-mysql
```

Zabbix Server выполнил обновление схемы БД. После запуска проверены журналы и состояние контейнеров.

## 5. Возникшие проблемы

**Zabbix Server не запускался**

Ошибка: `JavaGateway configuration parameter is not specified or empty`.

Причина — включённые Java-поллеры при отсутствии настроенного Java Gateway. Поскольку JMX-мониторинг не используется, установлено:

```ini
ZBX_STARTJAVAPOLLERS=0
```

После пересоздания контейнера сервер успешно запустился.

**Zabbix Agent был недоступен**

После обновления агента до 8.0 сервер не мог выполнять пассивные проверки.

В журнале обнаружено:

```text
connection from "172.16.238.2" rejected
allowed hosts: "127.0.0.1"
```

В `/etc/zabbix/zabbix_agentd.conf` разрешён адрес Docker-контейнера Zabbix Server:

```ini
Server=127.0.0.1,172.16.238.2
```

После перезапуска агента связь восстановлена.

> IP контейнера может измениться при пересоздании. Для постоянной эксплуатации требуется учитывать адресацию Docker-сети.

**Неподдерживаемые элементы данных**

Старый Zabbix Agent не поддерживал ключ `system.sw.packages.get`. После обновления агента до 8.0 ключ успешно возвращает список установленных RPM-пакетов в JSON.
